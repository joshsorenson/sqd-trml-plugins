Linear Issues Plugin

Display your Linear issues from current and past cycles on your TRMNL display

Quick Start

Easiest Method: Use the Recipe

The fastest way to get started is using the pre-configured recipe:

Add Linear Issues Recipe →

Manual Setup

Or follow these steps to set it up manually:

  1. Get your Linear API key from linear.app/settings/api
  2. Create a new plugin at trmnl.com/plugins
  3. Copy the configuration values below
  4. Paste each markup block into its tab
  5. Save and activate your plugin

Plugin Configuration

Strategy
Polling
Polling URL
https://trml-plugins.vercel.app/api/linear-issues
Polling Headers
x-linear-api-key={{ linear_api_key }}

TRMNL fills in {{ linear_api_key }} from the form field. The key travels in a header, so it never shows up in a URL or a log.

Polling Verb
GET
Polling Body
(leave empty)
Form Fields
- keyname: linear_api_key
  field_type: password
  name: Linear API Key
  description: Your personal Linear API key
  help_text: Create one in <a href="https://linear.app/settings/account/security" target="_blank">Linear Settings, Security and access</a>. It's sent as a header, never in the URL.
- keyname: max_issues
  field_type: number
  name: Maximum Issues
  description: Most issues to show on the full layout
  default: 11
  min: 3
  max: 11
  optional: true
  help_text: Between 3 and 11. Anything past that shows as "+N more". Smaller layouts show fewer so text stays readable.
- keyname: author_info
  name: About This Plugin
  field_type: author_bio
  category: productivity
  description: Shows your open Linear issues from the current and past cycles, oldest and most urgent first. Built by Josh Sorenson, VP of Systems at Church Media Squad.
  learn_more_url: https://trml-plugins.vercel.app/linear

Features

  • • Open issues from the current cycle, plus anything carried over from past cycles
  • • Oldest cycle first, then Urgent and High
  • • Counts for open, carried over and urgent
  • • A layout built for each screen size: full, half horizontal, half vertical and quadrant
  • • Built on the TRMNL framework only, so it reads cleanly on 1-bit screens
  • • Your API key is sent as a header, never in the URL
